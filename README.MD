Установка проекта
Шаг 1: Инициализация нового проекта
Если вы ещё не создали новый проект с управлением зависимостями через UV, выполните следующие команды:


uv init mcp-server-demo
cd mcp-server-demo
Теперь ваш проект готов к работе!

Шаг 2: Добавление зависимости
Чтобы добавить библиотеку MCP в список ваших зависимостей, используйте команду:


uv add "mcp[cli]"
Альтернативный вариант — использование стандартного менеджера пакетов pip, если вы предпочитаете именно этот инструмент:


pip install "mcp[cli]"
Как запускать проект?
Проект состоит из двух основных компонентов:

Серверная часть (server)
Клиентская часть (client)
⚙️ Запуск сервера
Для запуска вашего сервера введите следующую команду:


python -m server
При желании вы можете включить режим отладки, подключив инспектор MCP для удобного анализа состояния системы:


npx @modelcontextprotocol/inspector
🖥️ Запуск клиента
Клиентская сторона запускается отдельно командой:


python -m client
Таким образом, вы легко сможете управлять своим проектом с минимальными усилиями благодаря инструменту UV и стандартному набору команд.
